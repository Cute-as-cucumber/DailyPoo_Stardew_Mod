# Daily Poo 🚽

A [Stardew Valley](https://www.stardewvalley.net/) mod that adds a daily poop mechanic. Every farmer's gotta go.

## What it does

- **You must poop once per in-game day** — on a toilet, like a civilized farmer.
- Skip a day and you wake up **constipated**: your energy is capped at half until you finally go. Food and coffee can't save you.
- Robin mails you a **free toilet** when you start playing. Place it anywhere furniture is allowed (bathroom, bedroom, town square — I don't judge). Need more? Robin sells them for 500g.
- **Sit on the toilet** (right-click it) and stay seated for about **3 seconds** and nature takes its course. (Impatient? Press **P**.) Your farmer shows a heart bubble and a message appears in the corner: *"I feel lighter now!"*
- **Waste not:** each poop produces one Basic Fertilizer. The circle of farm life. Super eco friendly.
- Festival days are excused by default. Your toilet is at home; I understand.

## Requirements

- Stardew Valley **1.6.14 or later** (Windows, macOS, Linux, or Steam Deck)
- [SMAPI](https://smapi.io/) **4.0 or later**

## Installation

1. Install [SMAPI](https://smapi.io/) if you haven't already.
   - **Windows + Steam:** when the SMAPI installer finishes, copy the launch command it shows (including the quotes and `%command%`). In Steam, open **Stardew Valley → Properties → General → Launch Options** and paste it there. See the [official Windows guide](https://stardewvalleywiki.com/Modding:Installing_SMAPI_on_Windows).
   - **macOS:** follow the [official Mac guide](https://stardewvalleywiki.com/Modding:Installing_SMAPI_on_Mac) to avoid macOS security warnings. No Steam launch option is needed on Mac.
2. Download the latest `DailyPoo x.y.z.zip` from the [Releases](../../releases) page.
3. Find your game folder. In Steam, right-click **Stardew Valley → Manage → Browse local files**. Open its `Mods` folder, then unzip the download there so you end up with `Mods/DailyPoo/DailyPoo.dll`.
   - Default Windows path: `C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\Mods` (your Steam library may be on another drive)
   - macOS: `~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/MacOS/Mods`
   - Linux: `~/.steam/steam/steamapps/common/Stardew Valley/Mods`
4. Launch the game through Steam/SMAPI. Robin's letter arrives the next time a day starts.

Players only need Stardew Valley and SMAPI. The .NET SDK is required only for building the mod from source.

## Configuration

Edit `Mods/DailyPoo/config.json` (created after the first launch), or install
[Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) to change settings in-game.

| Setting | Default | What it does |
| --- | --- | --- |
| `PoopKey` | `P, LeftStick` | Key/button to poop while sitting on the toilet (`LeftStick` = clicking the left thumbstick). Supports any keyboard key or controller button. |
| `PlaySound` | `true` | Play a sound effect when pooping. |
| `PenaltyFraction` | `0.5` | Fraction of max energy available while constipated (0.05–1). |
| `Emote` | `heart` | Bubble shown after pooping: `heart` or `happy`. |
| `FestivalGrace` | `true` | No poop required on festival days. |
| `AutoPoop` | `true` | Sitting on the toilet for ~3 seconds poops automatically. |
| `ProduceFertilizer` | `true` | Each poop produces one Basic Fertilizer. |

## Compatibility

- Works on Windows, macOS, Linux, and Steam Deck — the same download for all platforms.
- Full controller support: sit with the usual interact button, and auto-poop means no extra button is ever required. The manual poop action defaults to clicking the left thumbstick, rebindable in the config.
- Works with existing saves. You get one grace day after installing; after that, nature calls daily.
- Safe to uninstall: remove the mod folder. Placed toilets will turn into an "error item" you can trash.
- Single-player focused. In multiplayer, only the host's state is saved (farmhands are untested).

## Building from source

1. Install the [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0) and have the game + SMAPI installed.
2. Run `dotnet build` in the `DailyPoo` folder.

The build uses [Pathoschild.Stardew.ModBuildConfig](https://www.nuget.org/packages/Pathoschild.Stardew.ModBuildConfig), which finds your game install automatically, copies the mod into your `Mods` folder for testing, and produces a ready-to-release zip in `bin/Debug/net6.0/`.

The toilet sprite is generated from an ASCII pixel map — edit the grid in `scripts/make_toilet_sprite.py` and re-run it to change the art.
